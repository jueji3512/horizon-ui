# 字体系统

## 字体家族

| 用途 | 字体栈 |
|------|--------|
| **正文 / UI / 代码** | JetBrains Mono, ui-monospace, Fira Code, Consolas, monospace |

## Body Token

正文和控件文本使用 `font-body-*` 工具类。

| Token | 字号 / 行高 | 用途 |
|-------|-------------|------|
| `font-body-sm` | `12px / 20px` | 辅助文本、行内代码、徽标文本 |
| `font-body-md` | `14px / 22px` | 默认正文、表单和常规控件文本 |
| `font-body-lg` | `16px / 24px` | 大尺寸控件文本、强调正文 |

## Title Token

标题使用 `font-title-*` 工具类，包含 600 字重。

| Token | 字重 / 字号 / 行高 | 用途 |
|-------|-------------------|------|
| `font-title-1` | `600 / 36px / 44px` | 一级页面标题 |
| `font-title-2` | `600 / 28px / 36px` | 二级页面标题 |
| `font-title-3` | `600 / 24px / 32px` | 分组标题 |
| `font-title-4` | `600 / 18px / 26px` | 小节标题 |
| `font-title-5` | `600 / 16px / 24px` | 卡片或区块标题 |
| `font-title-6` | `600 / 14px / 22px` | 紧凑标题 |
