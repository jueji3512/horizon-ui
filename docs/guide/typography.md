# 字体系统

## 字体家族

| 用途 | 字体栈 |
|------|--------|
| **正文 / UI** | Inter, ui-sans-serif, system-ui |
| **等宽 / 代码** | JetBrains Mono, ui-monospace |

## 字号阶梯

| Token | 字号 | 用途 |
|-------|------|------|
| `text-xs` | 12px | 辅助说明、标签 |
| `text-sm` | 14px | 次要正文 |
| `text-base` | 16px | 默认正文 |
| `text-lg` | 18px | 小标题 |
| `text-xl` | 20px | 模块标题 |
| `text-2xl` | 24px | 页面标题 |
| `text-3xl` | 30px | 一级标题 |
| `text-4xl` | 36px | Hero 标题 |
